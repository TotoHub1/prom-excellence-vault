# PLB Template (AM-PROM-311a)

## Omschrijving
Standaard Word-template voor het opmaken van een [[Plaatsbeschrijving]] (PLB). Wordt gebruikt bij intrede, uittrede of werken. De ingevulde template vormt het officiële verslag dat door beide partijen wordt ondertekend. ([[00_Sources/AM-PROM-311a TEMP Plaatsbeschrijving  (1).docx]])

## Structuur van de template

### Koptekst
| Veld | Waarde |
|------|--------|
| Naam Klant | |
| Contractnummer | |
| Opgemaakt door | |
| Datum van opmaak | |
| In opdracht van | |
| Type plaatsbeschrijving | Intrede / Uittrede / Werken |
| Datum in-/uittrede / start werken | |

### Partijen
Tabel: Partij · Naam · E-mail · GSM

### Lokaal
Per lokaal: Departement opdrachtgever / Departement uitvoerder / Klant / Gebouwnummer-naam / Lokaalnummer / Deurnummer / Niveau / Classificatie per lokaal

### Ligging
Algemeen plan toevoegen via [[Airport View]] (lokaalnummer op plan vermeld).

### Overzicht voorafgaand opgevraagde/te ontvangen documenten
| Soort | D.D. | Geldig tot | Opmerkingen |
|-------|------|-----------|-------------|
| Keuringsverslagen | | | |
| Onderhoudsattesten | | | |
| Vorige plaatsbeschrijving | | | |
| Andere | | | |

### Vaststellingen per ruimte
Algemene staat: Uitstekend / Net gerenoveerd / Vuil-slijtage / Zeer vuil-verouderd

Per ruimte (1, 2, ...): kolommen Beschrijving · Aantal · Algemene staat · Opmerkingen/Schade · Nummer Foto('s)

**Plafond:** Materiaal, Verlichtingsarmaturen, Branddetectoren, Ventilatieroosters, Sprinklerinstallaties, Noodverlichting

**Wanden:** Materiaal, Ramen, Schakelaars, Stopcontacten, Data aansluiting, Thermostaat

**Deuren:** Materiaal, Deuromlijsting, Deurstop, Deurkruk, Identificatiepaneel

**Vloer:** Materiaal, Plinten, Vloerdozen, Data

### Uitrustingen en voorzieningen
Deurbel, Intercominstallatie, Alarminstallatie, Brievenbus, Identificatiepaneel van de klant

### Meterstanden
| Type | Veld |
|------|------|
| Water | Watermeternummer, Watermeterstand |
| Elektriciteit | EAN code, Metertype (enkelvoudig / dag-nacht), Meternummer, Meterstand |
| Gas | EAN code, Meternummer, Meterstand |
| Calorimeter | Lokaal, Nummer, Schaal, Index |
