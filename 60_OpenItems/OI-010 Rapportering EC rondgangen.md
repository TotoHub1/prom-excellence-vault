# OI-010 — Rapporteringsvorm van E&C aan Property Manager n.t.b.

## Beschrijving
[[E&C]] voert rondgangen uit in multi user gebouwen, maar de manier waarop zij hierover rapporteren aan de [[Property Manager]] is nog niet vastgelegd.

## Context
Uit [[00_Sources/AM-PROM-332 Template planning periodieke rondgang.xlsx]]:
> "Vorm van de rapportering door E&C n.t.b."

De [[Property Manager]] neemt de E&C-rondgangen op in de planning ter opvolging (Uitvoerder = E&C).

## Wat is nodig om te sluiten?
- Rapporteringsvorm (verslag, mail, mondelinge overdracht) vastleggen
- Timing van de rapportering bepalen
- Vastleggen in SOP AM-PROM-330 of WI AM-PROM-331
