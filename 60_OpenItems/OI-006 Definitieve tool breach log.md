# OI-006 — Definitieve tool voor de breach log nog niet gekozen

## Beschrijving
De huidige [[Breach Log]] (AM-PROM-3X2) is een tussentijdse Excel-template per Business Department. De keuze van een definitieve tool (bv. SharePoint, Maximo, ander systeem) is nog niet gemaakt.

## Context
Uit [[00_Sources/AM-PROM-3X2 Breach Log Template.xlsx]]:
> "Tussentijdse log van de compliance breaches door gebruikers, tot de keuze van een definitieve tool. Op basis van deze template wordt beslist in welke tool de breach log wordt opgenomen; de open breaches worden dan overgezet."

## Wat is nodig om te sluiten?
- Evalueren van mogelijke tools (SharePoint, Maximo, ander)
- Beslissing nemen over definitieve tool
- Migratie open breaches van Excel naar nieuwe tool
- Locatie Excel-template in tussentijd bevestigen
