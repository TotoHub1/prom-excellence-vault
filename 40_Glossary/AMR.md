# AMR — Asset Modification Request

## Definitie
Een formele aanvraag voor een asset-gerelateerde wijziging, ingediend via [[HIF Back Office]] en geregistreerd in [[Maximo]]. ([[00_Sources/Asset Modification Request Handling Turtle.pptx]])

## Gebruik in context PROM/BAC
AMR is het centrale object in het [[AMR Handling]]-proces. Doorloopt stappen van intake tot closing met een volledige lifecycle trace in [[Maximo]].

## Synoniemen & varianten
- Asset Modification Request (volledige naam)
- Service Request AMR (aanduiding in Maximo-context)
