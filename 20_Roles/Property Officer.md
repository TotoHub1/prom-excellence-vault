# Property Officer

## Omschrijving
Voert periodieke rondgangen uit en maakt planningen op onder verantwoordelijkheid van de [[Property Manager]]. ([[00_Sources/AM-PROM-332 Template planning periodieke rondgang.xlsx]])

## Verantwoordelijkheden
- Planningen periodieke rondgangen opmaken
- Periodieke rondgangen uitvoeren (checklist AM-PROM-333)
- Verslagen opmaken en ter goedkeuring bezorgen aan [[Commercial Lead]]
([[00_Sources/AM-PROM-332 Template planning periodieke rondgang.xlsx]])

## Activiteiten
- [[Periodieke Rondgang]] — stap 1, 3, 4, 5
- [[Monitoren Verplichtingen]] — uitvoering rondgang

## Raakvlakken met andere rollen
- [[Property Manager]] — eindverantwoordelijke, ontvangt verslag
- [[Commercial Lead]] — goedkeuring verslag
- [[E&C]] — parallel uitvoerder in multi user gebouwen
