# E&C — Engineering & Construction

## Omschrijving
E&C beheert de gemeenschappelijke delen van multi user gebouwen en voert periodieke rondgangen uit in de gebouwen die zij beheren. De [[Property Manager]] neemt die rondgangen op in de planning ter opvolging (Uitvoerder = E&C). ([[00_Sources/AM-PROM-332 Template planning periodieke rondgang.xlsx]])

## Verantwoordelijkheden
- Rondgangen plannen en uitvoeren in multi user gebouwen
- Rapportering aan [[Property Manager]] (vorm n.t.b.)
- Gemeenschappelijke delen beheren (onderhoud, herstelling, vervanging)
([[00_Sources/AM-PROM-332 Template planning periodieke rondgang.xlsx]], [[00_Sources/AM-PROM-411 Template demarcatielijst.xlsx]])

## Activiteiten
- [[Periodieke Rondgang]] — uitvoering in multi user gebouwen
- [[Monitoren Verplichtingen]] — rol in bijhouden compliance-register (n.t.b.)

## Raakvlakken met andere rollen
- [[Property Manager]] — opdrachtgever en opvolger
- [[Property Officer]] — parallel uitvoerder in single user gebouwen

## Open punten
