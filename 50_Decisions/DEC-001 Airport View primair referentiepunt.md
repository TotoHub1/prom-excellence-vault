# Beslissing: Airport View is primair referentiepunt voor ruimtelijke consultatie

## Beschrijving
Airport View is aangeduid als het huidige primaire referentiepunt voor alle ruimtelijke consultaties binnen BAC Asset Management — Property Management.

## Context
Meerdere systemen bevatten ruimtelijke data (Airport View, Planon, AX, Maximo). Er is een expliciete uitspraak in de bron dat Airport View momenteel de primaire status heeft.

## Beslissing
> "Airport View is momenteel het primair referentiepunt voor ruimtelijke consultatie."

## Gevolgen
- Alle ruimtelijke opzoeking vertrekt vanuit [[Airport View]]
- Data-correcties lopen via [[ServiceNow]]
- Status "momenteel" impliceert dat dit kan wijzigen bij voltooiing van de [[Planon]]-transitie
